This Project will apply to jobs for you based.

It is meant to be very simple and apply some knowledge from my elders always be applying to jobs.

MVP Features
- Upload a resume, extract name, and save in a database to be later used to apply for jobs.
- Take a url, and apply to the job with the saved information.

Future features,
- Save the search terms for jobs users want to apply to, and link it to a resume.
- Automatically get a list of jobs, and surface them to the user to confirm if they want to apply
